# Advanced Driver Assistance Systems (ADAS)

> A comprehensive overview of **ADAS technologies**, their history, working principles, applications, and future role in autonomous mobility.

## Project Overview

Advanced Driver Assistance Systems (ADAS) are intelligent automotive technologies designed to improve road safety, reduce human error, and enhance driving comfort through automation, sensor fusion, and real-time decision-making. ADAS combines cameras, radar, LiDAR, ultrasonic sensors, AI, and embedded systems to help drivers avoid collisions and gradually bridge the gap toward autonomous vehicles. :contentReference[oaicite:0]{index=0}

---

## Core Objective

The main goal of ADAS is to:

-  Reduce accidents caused by human error  
-  Improve vehicle safety and road awareness  
-  Assist drivers through automation  
-  Enable semi-autonomous and future fully autonomous vehicles  

---

##  History of ADAS

- **1950s:** Anti-lock Braking System (ABS) introduced  
- **1948–1950s:** Ralph Teetor invented cruise control (Speedostat)  
- **1990s:** Adaptive Cruise Control (ACC) emerged  
- **2000s+:** Lane assist, blind spot monitoring, AEB, and sensor fusion systems expanded rapidly  
- **Today:** Level 2–3 automation with AI-enhanced systems is increasingly common :contentReference[oaicite:1]{index=1}

## Types of ADAS

### Passive ADAS
Provides warnings but driver takes action:
- Lane Departure Warning
- Blind Spot Warning
- Collision Alerts
- Driver Drowsiness Alerts

### Active ADAS
System can intervene automatically:
- Automatic Emergency Braking (AEB)
- Adaptive Cruise Control (ACC)
- Lane Keeping Assist (LKA)
- Autonomous Parking

## ⚙️ How ADAS Works

ADAS operates using **sensor fusion**, where multiple sensors collect and process environmental data.

- 📡 Radar  
- 🌐 LiDAR  
- 📍 GPS  
- 🔊 Ultrasonic Sensors
